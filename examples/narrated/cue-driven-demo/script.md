# From signal to decision

This demonstration has no spoken narration. The six lines below are authored
timing labels used to prove cue-driven visual and caption behavior.

1. A signal starts as a small change.
2. Context makes it visible.
3. First, remove noise.
4. Then compare it with a baseline.
5. Finally, choose one action.
6. A useful signal ends in a decision.

The generated 220 Hz synchronization tone is technical test audio. It is not a
voice, narration, music, a pronunciation sample, or evidence of a passed
pronunciation check.
