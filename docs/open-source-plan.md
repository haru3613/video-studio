# 開源整理計畫

本倉庫用於開發可獨立安裝的 Video Studio 開源版本。初始版本為私人準備
倉庫，使用全新 Git 歷史；既有製作工作區繼續保留。

第一個可執行版本的範圍：

- MCP 製作流程：企劃、旁白、分鏡、渲染、品質檢查與失敗恢復。
- 本機 Dashboard 與時間點審片回饋。
- 一支使用可再散布素材、無須付費 API 帳號的短範例。
- 安裝、設定、人工確認與故障排除文件。

正式上傳先列為進階選配，預設關閉。品牌、角色、聲音、頻道、憑證、
實際製作專案與營運紀錄留在各使用者自己的工作區。

依序完成以下三個交付階段：

1. **可安裝核心。** 盤點必要來源與相依，抽出渲染、配音及封面工具，
   分離品牌設定，設計保留信任檢查的 runtime 安裝流程。驗收：新環境
   不依賴原作者的私人 repo、素材或記憶，能安裝並讀取 MCP status。
2. **可重現範例。** 完成渲染、QA、審片與匯出，以及一次中斷恢復。
   驗收：範例影片可播放、變更素材後舊 QA 失效、缺少憑證時明確提示、
   未設定正式核准時不能上傳。範例結果不得冒充正式發布核准。
3. **公開候選版。** 完成乾淨環境 CI、秘密掃描、第三方與素材授權清單、
   文件檢查和最終差異審閱。由維護者決定授權與權利人，再確認公開及
   首次 release。

目前尚未決定 MIT 或 Apache-2.0，也未匯入產品程式、第三方 skills 或
製作素材。每次匯入應記錄精確來源版本及權利資訊；新歷史不能取代
第三方著作權告知。

初期以本機使用為目標。作業系統支援、付費 provider、發布核准及成片
品質，僅在完成對應實測後列入支援範圍。
