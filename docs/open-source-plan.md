# 開源整理計畫

本倉庫開發使用者自行安裝的 Video Studio。使用乾淨 Git 歷史，
現有製作工作區繼續保留。已依明列清單抽取程式，完成整合驗證與 code review。

2026-09-19 已確認的產品範圍：

- 完整 CLI，可操作製作、查狀態、恢復任務、QA 與匯出。
- 使用者自行架設 MCP，支援本機 stdio 和有驗證的私人伺服器 HTTP。
- CLI／MCP 共用工作流核心，皆可搭配網頁審片。
- 不提供雲端或代管服務；模型 provider 由使用者自行選配及設定金鑰。
- 第一版使用原創中性模板與免付費 API 的短範例，優先完成本機交付。

功能、模組介面、交付依賴、來源抽取清單與驗收條件，以
[功能實作計畫](implementation-plan.md) 為準。該文件內的命令及介面是
目標設計；實作進度與驗證界線記錄於 [validation](validation.md)。

最新實作範圍依使用者「基本上是複製我們既有的功能工作流」：保留進階
YouTube／簽章核准的相容原始碼與本機介面，預設不配置頻道／signer，
不開放 HTTP 發布。沒有啟用、代管或執行平台發布。品牌、角色、聲音、頻道、憑證、
實際製作專案與營運紀錄留在各使用者自己的工作區。

相依和再散布權利，記錄精確來源版本與必要 notices；新歷史不能取代
第三方著作權告知。第三方軟體、素材與模型各自遵守適用授權。

公開前需完成乾淨環境安裝、CLI／MCP 真實流程、秘密及授權盤點、文件
與 CI 驗證。維護者確認授權、公開及 release 後才發布；規劃文件與
原始系統的測試結果不代表新版本已經可用。
